Entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

`main.py` writes one invented word and its one-line definition to `/output/entry.txt`:

> Planfall — the quiet relief when a plan you dreaded falls through.

Everyone has felt it: the plan you were dreading collapses, and instead of disappointment there is a sudden, guilty lightness. English has words for the dread (dread, reluctance) and for the collapse (cancellation), but none for the relief itself. *Planfall* names that relief — a feeling-word in the line of *schadenfreude* and *saudade*, built from plain English parts so it reads as though the language grew it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic. See [CANDIDATES.md](CANDIDATES.md) for the full candidate list and the pick rationale.
